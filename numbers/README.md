| Page | Use it when you need |

| [Latency](latency.md) | The time an operation takes in memory, on disk, or across a network |
| [Powers of two and data sizes](powers-of-two-and-data-sizes.md) | Byte units, integer limits, and the size of a key space |
| [Time conversions](time-conversions.md) | Seconds in a day, month, or year, and per-day to per-second shortcuts |
| [Availability nines](availability-nines.md) | Permitted downtime, and the availability of components combined |
| [Traffic formulas](traffic-formulas.md) | Average and peak requests per second from daily active users |
| [Storage and object sizes](storage-and-object-sizes.md) | A working size for a record, a photo, or a minute of video |
| [Network and bandwidth](network-and-bandwidth.md) | Link speeds, transfer times, and bits against bytes |
| [Component capacity](component-capacity.md) | A first assumption for what one node can handle |
